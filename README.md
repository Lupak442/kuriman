# 🌰 쿠리만쥬 시메지 타이머 (Kurimanju Shimeji Timer)

애니메이션 **치이카와(Chiikawa)**의 **쿠리만쥬(밤만쥬 선배)** 캐릭터가 바탕화면과 실행 중인 창(크롬, 카카오톡, 파일 탐색기 등) 위를 돌아다니는 **데스크톱 시메지 + 포모도로 타이머 + 가방 북마크 런처** 프로그램입니다.

## ✨ 주요 기능
1. **타이머 & 포모도로 알람**
   - 타이머 시간을 설정하고 시작하면 쿠리만쥬가 화면 위에서 떨어지며 활동을 시작합니다.
   - 시간이 종료되면 시그니처 **「하아ー(ハーッ)!!」** 모션과 함께 완료 알림이 표시됩니다.
2. **시메지 물리 이동 & 창 올라타기**
   - **자율 행동**: 바닥 걷기, 양옆 벽 등반/하강, 천장 매달려 이동, 자유낙하, 맥주/안주 먹방(`꿀꺽 꿀꺽`), 숙취 휴식 모션
   - **외부 창 인식**: 크롬, 카카오톡, 파일 탐색기 등 창 모드로 띄워둔 창의 옆벽을 타고 올라가 지붕(타이틀바) 위를 산책하며, 풀창(최대화)이거나 창이 없을 때는 자동으로 모니터 테두리 모드로 전환됩니다.
   - **마우스 드래그**: 좌클릭으로 잡으면 머리 위를 잡힌 채 손발을 파닥거리며 낑낑거립니다.
3. **우클릭 보따리 가방 (사이트 북마크 런처)**
   - 쿠리만쥬를 우클릭(또는 잡은 채로 우클릭)하면 초록 가방을 여는 이펙트와 함께 사이트 런처가 열립니다.
   - 자주 가는 사이트(URL)를 추가/삭제하고 클릭해 기본 브라우저로 즉시 열 수 있습니다.

## 🚀 실행 방법
```bash
npm install
npm start
```
또는 Windows에서 `실행하기.bat` 파일을 더블클릭하여 바로 실행할 수 있습니다.
